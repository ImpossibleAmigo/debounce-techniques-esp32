# 🔘 Усунення брязкоту контактів кнопки (ESP32-S3)
**Модуль 2.4. Домашнє завдання**

Цей репозиторій містить реалізацію п'яти різних підходів до усунення брязкоту (debounce) тактової кнопки на мікроконтролері ESP32-S3 з використанням Arduino Framework.

## 🛠 Обладнання
- Платформа: ESP32-S3
- Тактова кнопка
- Резистор 10 кОм (Pull-up)
- Резистор 100 Ом (для RC-фільтра)
- Конденсатор 100 нФ (для RC-фільтра)

## 📊 Завдання 6: Порівняльна таблиця результатів

| Метод | Кількість хибних спрацювань | Затримка реакції | Складність | Коментар |
| :--- | :--- | :--- | :--- | :--- |
| **Без debounce (Task 1)** | Дуже багато | 0 мс | Найнижча | Систематичні багаторазові спрацювання при кожному натисканні та відпусканні. |
| **Time-based (Task 2)** | Середня (при відпусканні) | ~50 мс | Низька | Відфільтровує брязкіт при натисканні, але все ще можливі хибні реакції при фізичному відпусканні кнопки. |
| **State-based (Task 3)** | Відсутні | ~20 мс | Середня | Надійний програмний метод. Реагує рівно 1 раз на натискання і повністю ігнорує відпускання. |
| **Polling (Task 4)** | Відсутні | ~20-25 мс | Висока (програмна) | Найстабільніша поведінка машини станів. Не використовує переривання, не навантажує ядро обробниками ISR. |
| **Hardware RC (Task 5)** | Декілька (менше ніж у Task 1) | ~10 мкс | Висока (апаратна) | Брязкіт не зник повністю через задані в умові номінали. Стала часу розряду (100R * 100n) = 10 мкс, що занадто мало для фільтрації механічного брязкоту (5-20 мс). |
