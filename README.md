# 🔘 Усунення брязкоту контактів кнопки (ESP32-S3)
**Модуль 2.4. Домашнє завдання**

Цей репозиторій містить реалізацію п'яти різних підходів до усунення брязкоту (debounce) тактової кнопки на мікроконтролері ESP32-S3 з використанням Arduino Framework.

## 🛠 Обладнання
- Платформа: ESP32-S3
- Тактова кнопка
- Резистор 10 кОм (Pull-up)
- Резистор 100 Ом (для RC-фільтра)
- Конденсатор 100 нФ (для RC-фільтра)

## 📊 Завдання 6: Порівняльна таблиця результатів

| Метод | Кількість хибних спрацювань | Затримка реакції | Складність | Коментар |
| :--- | :--- | :--- | :--- | :--- |
| **Без debounce (Task 1)** | Дуже багато | 0 мс | Найнижча | Систематичні багаторазові спрацювання при кожному фізичному натисканні та відпусканні. |
| **Time-based (Task 2)** | Середня (при відпусканні) | ~50 мс | Низька | Відфільтровує брязкіт при натисканні, але все ще можливі хибні реакції при фізичному відпусканні кнопки. |
| **State-based (Task 3)** | Відсутні | ~20 мс | Середня | Надійний програмний метод. Реагує рівно 1 раз на натискання і повністю ігнорує брязкіт при відпусканні. |
| **Polling (Task 4)** | Відсутні | 20-25 мс | Висока (програмна) | Найстабільніша поведінка машини станів. Не використовує переривання, захищає ядро від зайвого навантаження. |
| **Hardware RC (Task 5)** | Декілька | ~10 мкс | Висока (апаратна) | Брязкіт зменшився, але повністю не зник. RC-ланцюг із заданими номіналами (100R + 100n) має занадто малу сталу часу розряду (~10 мкс) порівняно з тривалістю механічного брязкоту (5-20 мс). Для повного усунення брязкоту потрібен резистор більшого номіналу. |
